# Fomi Generation Studio

The Fomi AI content generation page, built with Next.js.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` starts the dev server
- `npm run build` creates a production build
- `npm run lint` runs ESLint

## Branches

- `main` is production
- `dev` is where feature branches are merged
